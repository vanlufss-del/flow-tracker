# 📱 Инструкция по установке PWA "Учёт переливов" на iPhone

## Что изменилось?
Теперь ваше приложение — это **Progressive Web App (PWA)**, которое:
- ✅ Работает БЕЗ интернета
- ✅ Устанавливается на главный экран как обычное приложение
- ✅ Хранит все данные локально на телефоне
- ✅ Открывается в полноэкранном режиме (без адресной строки Safari)

---

## 🚀 Способ 1: Через хостинг (РЕКОМЕНДУЕТСЯ)

### Шаг 1: Загрузите файлы на бесплатный хостинг

Вам нужно разместить все 5 файлов в интернете:
1. `index.html`
2. `manifest.json`
3. `sw.js`
4. `icon-192.png`
5. `icon-512.png`

**Лучшие бесплатные варианты:**

#### A) GitHub Pages (рекомендуется)
1. Зарегистрируйтесь на https://github.com
2. Создайте репозиторий (например, `flow-tracker`)
3. Загрузите все 5 файлов
4. Settings → Pages → Source: `main branch`
5. Ваше приложение будет доступно по адресу: `https://ваш-ник.github.io/flow-tracker`

#### B) Netlify Drop (самый простой)
1. Перейдите на https://app.netlify.com/drop
2. Перетащите все 5 файлов в окно браузера
3. Готово! Получите ссылку типа `https://случайное-имя.netlify.app`

#### C) Vercel
1. Зарегистрируйтесь на https://vercel.com
2. Создайте новый проект и загрузите файлы
3. Получите ссылку

### Шаг 2: Откройте ссылку на iPhone

Откройте полученную ссылку в Safari на iPhone.

### Шаг 3: Установите на главный экран

1. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх) внизу Safari
2. Прокрутите вниз и выберите **"На экран «Домой»"**
3. Нажмите **"Добавить"**

### Шаг 4: Готово! 🎉

Теперь на главном экране появилась иконка приложения. Откройте её:
- Приложение откроется в полноэкранном режиме
- Будет работать БЕЗ интернета
- Все данные сохраняются локально

## 🔧 Способ 2: Локально через приложение (БЕЗ интернета вообще)

Если вы НЕ хотите размещать файлы в интернете вообще:

### Вариант A: Documents by Readdle
1. Скачайте приложение **"Documents by Readdle"** из App Store (бесплатно)
2. Скопируйте все 5 файлов в приложение Documents
3. Нажмите на `index.html` → он откроется во встроенном браузере
4. **НО:** PWA-функции (установка на экран, иконка) работать НЕ будут
5. Зато localStorage будет работать для сохранения данных

### Вариант B: Локальный сервер
1. Скачайте приложение **"HTTP Server"** из App Store
2. Загрузите все 5 файлов в папку сервера
3. Запустите сервер
4. Откройте в Safari адрес `http://localhost:8080`
5. Установите на главный экран как в Способе 1

## ❓ Проверка работы PWA

После установки на главный экран проверьте:

1. **Офлайн режим:** 
   - Включите режим полёта
   - Откройте приложение
   - Всё должно работать!

2. **Локальное хранилище:**
   - Добавьте операцию
   - Закройте приложение
   - Откройте снова
   - Данные должны остаться!

3. **Полноэкранный режим:**
   - Приложение открывается без адресной строки Safari
   - Выглядит как нативное приложение

## 🐛 Возможные проблемы

### Проблема: "Не могу установить на главный экран"
**Решение:** PWA работает только через HTTPS. Используйте GitHub Pages / Netlify / Vercel (все дают HTTPS).

### Проблема: "Данные пропадают"
**Решение:** 
- Не очищайте кеш Safari
- Не удаляйте приложение с главного экрана
- В настройках Safari → Дополнения → отключите "Предотвращение перекрёстного отслеживания" для вашего сайта

### Проблема: "Service Worker не регистрируется"
**Решение:** 
- Проверьте консоль Safari (Settings → Safari → Advanced → Web Inspector)
- Убедитесь, что все файлы лежат в одной папке

## 📝 Что в комплекте?

1. **index.html** — главный файл приложения (ваш обновлённый HTML)
2. **manifest.json** — настройки PWA (название, иконки, цвета)
3. **sw.js** — Service Worker для офлайн режима
4. **icon-192.png** — иконка 192×192 для установки
5. **icon-512.png** — иконка 512×512 для больших экранов
